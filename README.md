# Campus Skill Exchange Platform

A web-based platform designed to connect students based on their skills, learning interests, and peer-learning requirements.

The main goal of this project is to create a campus environment where students can find other students who can teach, learn, or collaborate with them on different skills.

## 🎯 Objectives

* Connect students based on their skills and interests
* Allow students to offer and learn different skills
* Manage learning requests between students
* Find suitable skill-based matches
* Provide a simple platform for peer-to-peer learning
* Apply Data Structures and Full-Stack Development concepts

## 🛠️ Technologies

* **Frontend:** HTML, CSS
* **Backend:** Python, Flask
* **Database:** MySQL
* **Data Structures:** HashMap, Graph, Queue, Priority Queue, Sorting
* **API:** REST API

## 🧩 Data Structures Used

### HashMap

Used for efficient mapping of students and their skills.

### Graph

Used to represent relationships between students based on common skills and learning interests.

### BFS / DFS

Used to explore student-skill connections and find related learners.

### Queue

Used for managing learning requests.

### Priority Queue

Used to prioritize suitable student matches.

### Sorting

Used to arrange and rank matching students according to relevant criteria.

## 📌 Planned Features

* Student registration and login
* Student profile management
* Add and manage skills
* Search for students with specific skills
* Send and manage learning requests
* Skill-based student matching
* Learning session management
